## 5. Moderation and reporting

**Every published referral code is reviewed by a human before it becomes publicly visible.**
Codes that fail review never appear.

A code can still stop working after approval (for example, a merchant ends its program), so
the Service provides two further mechanisms:

- **User reports**: after copying a code, you can report it as worked / did not work /
  invalid / program discontinued. Reports feed the code's quality score, and a code with too
  high a failure ratio is delisted automatically.
- **Expiry dates**: a publisher may set an expiry date, and the code is delisted
  automatically once it passes. A code published without one stays listed until reports
  trigger automatic delisting, the publisher takes it down, or a moderator removes it.

To report objectionable content, use the reporting feature in the app or email
