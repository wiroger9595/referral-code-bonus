# Play 內容分級與目標對象

Play Console → 應用程式內容 →「內容分級」（IARC 問卷）與「目標對象和內容」。

問卷答案會直接決定分級。**答錯比答得保守嚴重得多** —— 事後被查出不符會重新分級甚至下架。

---

## 內容分級問卷（IARC）

先選類別：**社交、通訊或內容分享**（有使用者產生的內容，選這類；
選「工具程式」會漏掉 UGC 相關的追問）。

| 題目 | 答案 | 說明 |
|---|---|---|
| 暴力 | 否 | |
| 性內容或裸露 | 否 | |
| 粗俗用語 | 否 | |
| 管制物質（毒品、酒精、菸草） | 否 | |
| **賭博** | **否** | 不提供任何形式的博弈或模擬博弈 |
| 恐懼元素 | 否 | |
| **使用者可以互動嗎** | **是** | 使用者上架的推薦碼與備註會公開顯示給其他人 |
| 使用者之間可以直接通訊嗎 | **否** | 沒有私訊、留言或聊天功能 |
| 使用者可以分享自己的位置嗎 | 否 | |
| 會分享使用者提供的個人資訊給第三方嗎 | 否 | |
| **app 是否提供使用者產生的內容的檢舉機制** | **是** | 複製後的回報流程，另有 robertsmart1989@gmail.com |
| 會不會分享使用者的下載或購買記錄 | 否 | |
| 是否為數位商店或商品目錄 | **是** | 目錄型 app，但不販售、不經手交易 |

### 兩題容易答錯的

**「是否涉及真實貨幣的交易或獎勵」** —— 推薦碼確實會讓使用者從服務商那裡拿到現金回饋，
但**本 app 不經手任何金流、不發放獎勵、也不販售任何東西**。
如果問卷有這類問題，據實說明「獎勵由第三方商家直接發放，本 app 不參與交易」。
不要因為畫面上出現「現金回饋 500 元」就答成 app 內有金錢交易，那會被歸到金融類而觸發額外審查。

**「金融產品」** —— 目錄裡若有銀行與券商，Play 的 Financial Services 政策可能被觸發。
我們的立場是：本 app **不提供**金融服務、不媒合貸款、不受理申辦，只是把商家自己的
公開註冊頁列出來。這段說明也寫進了 `../app-store/review-notes.md`，Play 這邊如果被要求
補件，用同一套說法。

送出前務必自己再讀一次 Play Console 當下的 Financial Services 政策條文，
這一塊 Google 這幾年改得很勤。

## 預期分級

以上答案預期會得到 **PEGI 3 / ESRB Everyone / 台灣：普遍級**，
但因為有 UGC，實際結果可能高一級。以問卷跑出來的為準，不要自己指定。

## 目標對象和內容

| 題目 | 答案 |
|---|---|
| 目標年齡層 | **18 歲以上** |
| app 會吸引兒童嗎 | 否 |
| 是否加入「兒童專屬」計畫（Teacher Approved 等） | 否 |

**選 18 歲以上的理由**：目錄內容涉及銀行開戶、信用卡、證券帳戶這類只有成年人能申辦的服務。
選 13+ 或更低會讓 app 落入 Play 的 Families 政策範圍，那套規則對 UGC、廣告 ID 與
資料蒐集的要求嚴格得多，對這個 app 沒有任何好處。

畫面設計上也不要出現卡通吉祥物或明顯針對兒童的視覺元素 —— Play 會用截圖判斷
「是否吸引兒童」，跟你自己填的答案不一致時以他們的判斷為準。
